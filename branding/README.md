# TonyAI brand assets

The TonyAI mark combines a friendly dark-skinned humanoid robot with connected nodes to communicate helpful intelligence, approachability, and collaboration. The character is rendered as a clean, non-photorealistic vector-style bust so the mark remains legible across product surfaces.

## Files

- `tonyai-logo-mark.png` — 1920×1920 transparent symbol for large-format use.
- `tonyai-favicon.png` — 1920×1920 transparent symbol optimized for favicon scaling.
- `tonyai-logo.svg` — editable logo lockup with the TonyAI wordmark.
- `tonyai-favicon.svg` — scalable favicon wrapper.

## Palette

- Deep navy: `#0B1F4D`
- Electric cyan: `#10B7EE`
- Accent violet: `#7C3AED`

Use the symbol alone at small sizes. Use `tonyai-logo.svg` when the TonyAI name should be visible.
